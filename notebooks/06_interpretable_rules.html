06 Interpretable Rule Extraction¶

This notebook aims to extract simple, human-readable rules from the Phase 2 dataset.

The goal is not to improve prediction accuracy, but to simplify the descriptor space and identify interpretable regimes associated with hydrovoltaic performance.

# Preprocessor
def build_preprocessor(df_input, features):
    numeric_features = []
    categorical_features = []

    for col in features:
        if pd.api.types.is_numeric_dtype(df_input[col]):
            numeric_features.append(col)
        else:
            categorical_features.append(col)

    numeric_transformer = Pipeline(steps=[
        ("imputer", SimpleImputer(strategy="median"))
    ])

    categorical_transformer = Pipeline(steps=[
        ("imputer", SimpleImputer(strategy="most_frequent")),
        ("onehot", OneHotEncoder(handle_unknown="ignore", sparse_output=False))
    ])

    preprocessor = ColumnTransformer(
        transformers=[
            ("num", numeric_transformer, numeric_features),
            ("cat", categorical_transformer, categorical_features)
        ],
        remainder="drop"
    )

    return preprocessor

Rule-based analysis reveals that hydrovoltaic performance can be described by a simple two-regime framework governed primarily by internal resistance and structural characteristics.

Devices with low internal resistance consistently exhibit higher power output, forming a high-performance regime, while high-resistance systems are associated with significantly lower performance.

Within each regime, structural features such as porosity further modulate performance, indicating that transport pathways play a secondary but important role.

These findings suggest that continuous descriptors capturing system-level transport behavior provide a more reliable representation of hydrovoltaic performance than discrete mechanism classifications.

# Add simplified high / low rule labels
def assign_simplified_rule(row):
    r_regime = row["R_descriptor"]
    structure = str(row["structure_class"])

    if r_regime == "low_R_regime":
        return "Rule 1: low R → higher power"
    elif r_regime == "high_R_regime" and "porous" in structure:
        return "Rule 2: high R + porous → lower power"
    elif r_regime == "high_R_regime":
        return "Rule 3: high R → lower power"
    else:
        return "Other"

df_rules["simplified_rule"] = df_rules.apply(assign_simplified_rule, axis=1)

rule_summary = (
    df_rules
    .groupby("simplified_rule")[TARGET]
    .agg(["count", "mean", "std", "min", "max"])

Saved final descriptor and rule summaries.

A simplified descriptor based on internal resistance is sufficient to separate hydrovoltaic systems into two distinct performance regimes. Devices with low resistance consistently exhibit higher power output, while high-resistance systems are associated with significantly reduced performance.

Structural features further modulate performance within each regime, with film-based structures generally outperforming porous systems under comparable resistance conditions. However, resistance remains the dominant factor governing system behavior.

These results demonstrate that hydrovoltaic performance can be effectively described using a low-dimensional descriptor space defined primarily by internal resistance, with structural characteristics providing secondary refinement.
